# Presets

`eslint-plugin-typedoc` ships flat-config presets to support incremental documentation policy adoption.

## Preset list

- [`typedoc.configs.minimal`](./minimal.md)
- [`typedoc.configs.recommended`](./recommended.md)
- [`typedoc.configs.markdown`](./markdown.md)
- [`typedoc.configs.tsdoc`](./tsdoc.md)
- [`typedoc.configs.jsdoc`](./jsdoc.md)
- [`typedoc.configs.strict`](./strict.md)
- [`typedoc.configs.all`](./all.md)

## Companion plugin for broader comment requirements

If you want configurable enforcement for required comments, required tags, or broader auditing beyond this plugin's TypeDoc-focused correctness rules, pair it with [`eslint-plugin-tsdoc-require-2`](https://www.npmjs.com/package/eslint-plugin-tsdoc-require-2).
